# Sửa lỗi và kiểm chứng — 2026-10-25

Báo cáo này ghi snapshot trước đợt tối ưu SLA tiếp theo. Xem [bản mới hơn: 426 tests + 50 subtests, agent persistence và soak](SLA_TARGET_20261025.md); các báo cáo/hashes bên dưới được giữ theo snapshot ban đầu.

Bản hiện tại qua **407 tests và 50 subtests**, không fail/skip. Đây là các trường hợp đã kiểm chứng; chưa thể cam kết mọi lỗi có thể xảy ra đều đã biến mất. **SLA HTTP đầu cuối p99 30 ms chưa đạt.**

## Các lỗi đã sửa

| Nhóm | Lỗi và hành vi sau sửa |
|---|---|
| Runtime input | Integer quá lớn và completion timestamp tràn số được từ chối trước admission, tránh HTTP 500 hoặc dừng owner. |
| CALL/CDR | Kiểm liên kết hai chiều cho operation mới cùng event_id; retry dùng digest và kết quả đã commit, nhất quán khi cache bị đẩy ra và sau restart. Không để lại reservation rỗng khi từ chối. |
| Phục hồi pending | Kiểm Future sau replay; lỗi, cancellation hoặc chưa resolve đều chặn startup với yêu cầu recovery/migration. Không checkpoint vượt qua bản ghi chưa xử lý. Test xác nhận ledger và metadata giữ nguyên khi xung đột. |
| Chấm bù | Giữ queue tới khi xử lý thành công; rollback retro/stats khi policy lỗi. Restore state thất bại dừng owner. Breaker có thể hồi phục khi idle sau cooldown. |
| Retro alerts | Retry publish trước khi drain thêm; giới hạn batch theo bộ đệm và chia replay thành từng phần để không ghi đè alert chưa publish. |
| Evidence | Đối chiếu durable ACK với journal, phát hiện mất file hoặc mất tail dù phần còn lại có hash chain hợp lệ. Không nhầm sampled ALLOW/CDR. |
| Isolation Forest | Kiểm shape/finite/range trước native kernel; singleton trả 0,5; lượng tử float32 như sklearn để tránh lệch sát threshold. |
| Voice API | Analyzer/predict chạy ngoài event loop. Chỉ delivery mới, đúng mode/artifact và trong deadline được action; duplicate luôn NONE. Cancel không giải phóng slot trước khi future thật hoàn tất. |
| Voice recovery | Lookup journal trước analyzer/model. Retry kết quả v1 hoàn tất được đọc qua canonical metadata như lịch sử, không diễn giải lại feature v1 bằng model v2. |
| Voice deadline/shutdown | Dùng perf_counter nhất quán; đúng hoặc quá deadline không actionable. Shutdown có timeout rõ ràng và giữ capacity khi native worker còn chạy. |
| WAV/model | Đo saturation từ PCM nguồn theo bit depth, sửa bỏ lọt PCM8 dương. Output probability/classes/shape sai chuyển OBSERVE/NONE, score null. |
| Spark | Chặn checkpoint khác engine và orphan Spark offsets; quarantine completion overflow và timing overrides; CSV kiểm header theo schema thay vì âm thầm gán lại cột. |
| HMAC/verifier | Test client dùng timestamp duy nhất trên Windows. Shutdown verifier không để lỗi pipe che mã thoát server; bỏ watchdog dump định kỳ khỏi timed run. |

Runtime giữ SQLite WAL/FULL và trả kết quả sau COMMIT. PENDING/durable=false cần retry cùng ID/payload với chữ ký mới và deadline cuộc gọi gốc. Liên kết CALL/CDR áp dụng khi hai operation cùng event_id; standalone CDR vẫn được nhận.

## Native crash của watchdog chẩn đoán

Đã tái hiện độc lập trên CPython 3.12.4 với cùng workload tạo/hủy code objects, chỉ đổi việc bật watchdog: hai control exit 0; hai lượt faulthandler.dump_traceback_later access violation 0xC0000005 trong khoảng 0,43–0,50 giây. Probe chỉ dùng thư viện chuẩn. [Kết quả đối chứng](../runtime/artifacts_v22/logs/native-watchdog-paired-20261022.json), [script/log lưu lại](../runtime/verification_20261025/native/README.md).

Verifier đã bỏ dump stack định kỳ khỏi timed run, giữ fatal diagnostics. Lượt HTTP Windows 90 giây đã hoàn tất trên đường code này. Đây là bằng chứng watchdog có thể crash độc lập; chưa có native debugger trace để khẳng định cùng địa chỉ C với lần crash lịch sử. Không coi việc bỏ watchdog là bản vá cho mọi native lỗi.

## Tương thích giọng nói và chạy lại

Schema acoustic hiện là **voice-acoustic-v2** vì clipping được đo từ PCM nguồn. Artifact v1 cần trích lại feature, train và calibration bằng corpus phù hợp; không dùng v1 model với v2 feature. Kết quả v1 đã hoàn tất có thể đọc lại dưới dạng duplicate/NONE khi payload khớp.

`FRAUD_AUDIO_SHUTDOWN_TIMEOUT_S` mặc định 10 giây. Timeout báo worker còn chạy; Python không thể kill native thread an toàn. Chưa có corpus WAV thật có nhãn để chứng nhận model âm thanh.

Chạy regression với một basetemp mới, không trỏ vào thư mục có dữ liệu cần giữ:

```powershell
$testTemp = Join-Path $env:TEMP ("telecom-verify-" + [guid]::NewGuid().ToString("N"))
python -B -m pytest -q -p no:cacheprovider tests spark/test_stateful_stream.py spark/test_distributed_stream.py spark/test_stream_contracts.py --basetemp $testTemp
```

Hướng tối ưu SLA tiếp theo: đo trên storage có fsync tail thấp và CPU ổn định, tách receive/auth/queue/model/COMMIT/response, rồi chạy steady-state/burst trên adapter mục tiêu. Giữ acknowledgement sau commit; không tăng số owner trên cùng SQLite để lấy số đo đẹp. Xem [SLA_30MS.md](SLA_30MS.md) và [DEVELOPMENT_V22.md](DEVELOPMENT_V22.md).
